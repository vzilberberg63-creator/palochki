# Палочки

Браузерная игра для [Яндекс Игр](https://yandex.ru/games/): палочками для еды разбираешь кучу риса и других зёрен по лоткам.
Идея — из ролика «гипнотический челлендж с рисом», где палочки вытаскивают чёрные зёрна из смеси с белыми.

## Как играть

- Нажмите на зерно — палочки его возьмут.
- Отпустите над лотком нужного вида: верно — `+1`, чужой лоток — ошибка, зерно отлетает обратно.
- Ведите по пустому месту — палочки разгребают кучу и открывают спрятанные зёрна.
- Уровень пройден, когда все целевые зёрна в лотках. Звёзды — за отсутствие ошибок и запас времени.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который напечатает Vite. Добавьте `?debug` к адресу — игра будет доступна в консоли как `window.__game`.

```bash
npm test
```

```bash
npm run zip
```

`npm run zip` собирает `palochki.zip` — архив для загрузки в консоль разработчика Яндекс Игр (`index.html` в корне, все пути относительные).

## Архитектура

TypeScript + Vite + Canvas 2D, без игрового движка. Логика отделена от отрисовки и покрыта тестами (Vitest).

```
src/
  core/            чистая логика, без DOM
    rng.ts         детерминированный генератор (mulberry32), seed уровня по номеру
    grains.ts      виды зёрен: форма, размер, цвет; «двойники»
    level.ts       генерация уровней и кривая сложности
    physics.ts     зёрна-окружности: расталкивание, импульсы, трение, пространственная сетка
    session.ts     состояние уровня: палочки, захват, лотки, ошибки, таймер, звёзды
    world.ts       геометрия мира 1000×1000: стол, лотки
  render/
    renderer.ts    отрисовка стола, лотков, зёрен, палочек и эффектов
  platform/
    platform.ts    Yandex Games SDK (+ заглушка для локального запуска), сохранения
  i18n.ts          русский / английский
  main.ts          игровой цикл (фиксированный шаг 1/60), ввод, экраны
tests/             тесты ядра
```

### Яндекс Игры

`platform.ts` подгружает `/sdk.js` (так SDK отдаётся на хостинге Яндекса). Если SDK нет — работает локальная заглушка.

- `LoadingAPI.ready()` — когда меню готово.
- `GameplayAPI.start()/stop()` — начало/конец/пауза уровня.
- Полноэкранная реклама между уровнями, начиная с 3-го.
- Прогресс: `player.setData` в облаке и копия в `localStorage`; при загрузке берётся лучшее из двух.
- Пауза при сворачивании вкладки и по событию `game_api_pause`.
- Язык из `environment.i18n.lang`: русский для СНГ, иначе английский.

## Сложность

Кривая `difficulty(n) = 1 − e^{−(n−1)/14}`: 0 на первом уровне, плавно стремится к 1. От неё зависят все параметры (`src/core/level.ts`):

| Параметр | Уровень 1 | Поздние уровни | Что даёт |
|---|---|---|---|
| Виды зёрен | 2 | до 8 | новый вид каждые 3 уровня, он всегда среди целей |
| Лотков (целей) | 1 | до 4 | больше решений на каждое зерно |
| Зёрен всего | ~46 | ~340 | плотнее куча, цели спрятаны |
| Размер зёрен | ×1.25 | ×0.8 | труднее попасть |
| Радиус захвата | 26 | 12 | нужна точность |
| Трение стола | высокое | низкое | куча разъезжается при разгребании |
| Таймер | нет | с 4-го уровня, всё меньше секунд на зерно | темп |
| Дрожание палочек | нет | с 8-го уровня | точность |
| Выскальзывание | нет | с 10-го уровня, при быстром движении | аккуратность |
| «Двойники» | нет | с середины кривой | похожие зёрна в смеси (белый рис / белая фасоль, красная чечевица / красная фасоль) |

Уровни 1–3 — обучение, заданы вручную. Остальные генерируются по номеру, одинаково у всех игроков.

## Дальше

1. **Мобильная раскладка.** Мир сейчас квадратный: в портретной ориентации зёрна получаются мелкими. Нужен вытянутый мир для портрета (лотки внизу, стол выше) и, возможно, смещение кончиков палочек над пальцем, чтобы палец не закрывал зерно.
2. Звук: шорох зёрен, стук палочек, звук лотка (с выключением при паузе и рекламе — требование Яндекса).
3. Комбо за серию верных переносов, награда за видео (`showRewardedVideo`) — например, +30 секунд.
4. Новые механики: несколько зёрен за раз, «мусор», который нельзя трогать, меняющийся фон.
5. Балансировка по реальным данным прохождения.
