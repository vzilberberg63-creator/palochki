# Палочки

Браузерная игра для [Яндекс Игр](https://yandex.ru/games/): палочками для еды разбираешь кучу риса и других зёрен по лоткам.
Идея — из ролика «гипнотический челлендж с рисом», где палочки вытаскивают чёрные зёрна из смеси с белыми.

## Как играть

В игре два режима.

### «Кучки» (основной, как в ролике)

- Прижмите палочки к столу и ведите: они работают как лопатка и сгребают зёрна.
- Отделите нужные зёрна от общей кучи и столкните их кучкой в копилку на краю стола.
- Свои зёрна, заехавшие в копилку, остаются там. Чужое зерно в копилке — ошибка; нажмите на него, и палочки выбросят его обратно на стол. Пока в копилке есть чужие зёрна, уровень не пройден.
- Кучка, въехавшая в копилку разом, — это сразу длинное комбо.

### «По зёрнышку»

- Нажмите на зерно — палочки его возьмут.
- Отпустите над лотком нужного вида: верно — `+1`, чужой лоток — ошибка, зерно отлетает обратно.
- Ведите по пустому месту — палочки разгребают кучу и открывают спрятанные зёрна.
- Уровень пройден, когда все целевые зёрна в лотках. Звёзды — за отсутствие ошибок и запас времени.
- Быстрая серия верных переносов — комбо: больше очков и дополнительное время.
- У каждого уровня таймер с обратным отсчётом; последние 10 секунд часы тикают.
- За пройденные уровни дают монеты, на них в магазине покупаются стили палочек.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который напечатает Vite. Добавьте `?debug` к адресу — игра будет доступна в консоли как `window.__game`.

```bash
npm test
```

```bash
npm run zip
```

`npm run zip` собирает `palochki.zip` — архив для загрузки в консоль разработчика Яндекс Игр (`index.html` в корне, все пути относительные).

## Архитектура

TypeScript + Vite + Canvas 2D, без игрового движка. Логика отделена от отрисовки и покрыта тестами (Vitest).

```
src/
  core/            чистая логика, без DOM
    rng.ts         детерминированный генератор (mulberry32), seed уровня по номеру
    grains.ts      виды зёрен: форма, размер, цвет; «двойники»
    level.ts       генерация уровней и кривая сложности
    economy.ts     монеты и награды за рекламу
    skins.ts       стили палочек и цены
    physics.ts     зёрна-окружности: расталкивание, импульсы, трение, пространственная сетка
    session.ts     состояние уровня «По зёрнышку»: палочки, захват, лотки, ошибки, таймер, звёзды
    heap.ts        режим «Кучки»: палочки-лопатка, копилки на столе, чужие зёрна
    world.ts       раскладки мира под форму экрана: стол, лотки
  render/
    renderer.ts    отрисовка стола, лотков, зёрен, палочек и эффектов
  audio/
    sound.ts       синтез звуков через Web Audio, без аудиофайлов
  platform/
    platform.ts    Yandex Games SDK (+ заглушка для локального запуска), сохранения
  settings.ts      настройки игрока (звук вкл/выкл)
  i18n.ts          русский / английский
  main.ts          игровой цикл (фиксированный шаг 1/60), ввод, экраны
tests/             тесты ядра
```

### Режим «Кучки»

`HeapSession` (`src/core/heap.ts`) наследует от `Session` всё общее — зёрна, физику, таймер, комбо, очки, продление за рекламу — и меняет управление и правила:

- **Лопатка.** Пока палец/кнопка нажаты, палочки прижаты к столу. Толкатель — три отрезка-капсулы: середина поперёк движения и загнутые вперёд края, как совок. Лопатка разворачивается за движением, а в начале мазка сразу встаёт поперёк него, чтобы не начинать боком.
- **Без проскоков.** Путь лопатки за кадр проходится шагами по 5 единиц, поэтому быстрым движением кучку не «проскочить»; зерно, которого коснулась лопатка, перенимает её скорость и не разъезжается в стороны.
- **Копилки** стоят на самом столе (`heapLayout`) и доходят до бортика: кучку прижимают к краю — она внутри. Куча в начале уровня появляется только на свободной части стола.
- **Ошибки** — число разных чужих зёрен, попавших в копилки (повторный заезд того же зерна не считается). Чужое зерно убирается нажатием на него.
- **Уровни** — свой генератор `generateHeapLevel`: обучение «чёрный рис из белого», дальше до трёх копилок, больше зёрен, уже лопатка, ниже трение (кучка рассыпается, если толкать резко), меньше времени.

Прогресс у режимов раздельный (`progress.heap`), монеты и палочки общие. Выбранный режим запоминается.

### Раскладки под экран

Форма мира выбирается при старте уровня по форме экрана (`src/core/world.ts`):

| Экран | Раскладка | Мир | Лотки |
|---|---|---|---|
| Телефон вертикально | `portrait` | 600 × 900–1260 | в ряд снизу |
| Телефон горизонтально, десктоп | `wide` | 860–1200 × 600 | столбиком справа |
| Планшет, почти квадратное окно | `square` | 1000 × 1000 | в ряд снизу |

Узкая сторона мира на телефоне — 600 единиц, поэтому зёрна там примерно в 1,6–1,7 раза крупнее, чем в квадратном мире. На большом экране масштаб ограничен 1:1.

Касание пальцем: зерно в палочках поднимается на 70 единиц выше пальца, чтобы палец его не закрывал, а радиус захвата у пальца на 10 единиц больше, чем у мыши.

### Комбо и очки

Серия — верные переносы подряд, каждый не позже чем через 3,5 с после предыдущего (`COMBO_WINDOW` в `src/core/session.ts`). Ошибка или пауза дольше окна обрывают серию.

| Серия | Множитель | Очки за зерно |
|---|---|---|
| 1–2 | ×1 | 10 |
| 3–5 | ×2 | 20 |
| 6–9 | ×3 | 30 |
| 10+ | ×4 | 40 |

- На уровнях с таймером каждые 5 зёрен подряд добавляют 2 секунды.
- В углу стола — плашка с множителем, длиной серии и полоской оставшегося окна.
- Рост множителя — вспышка «×N!» и восходящий аккорд; обрыв серии от 3 зёрен — мягкий нисходящий звук.
- На экране результата — очки и лучшее комбо. Рекорд очков по уровню сохраняется вместе с прогрессом.

### Таймер

Таймер есть у каждого уровня: на обучении (1–3) по 5 секунд на зерно плюс 12 секунд, дальше всё меньше — до 1,7 секунды на зерно. Вдоль верхнего края стола — полоска оставшегося времени (зелёная → жёлтая → красная), в HUD — обратный отсчёт. Последние 10 секунд полоска и часы пульсируют, каждую секунду звучит тик, последние три — выше и громче.

### Монеты и магазин палочек

Монеты (`src/core/economy.ts`) даются только за победу: `5 + 5 × звёзды + очки / 100`. Уровень на три звезды с хорошим комбо — 25–35 монет.

Стили палочек (`src/core/skins.ts`) — только внешний вид, на захват и сложность не влияют, чтобы покупка не давала преимущества:

| Стиль | Цена |
|---|---|
| Классические | бесплатно |
| Бамбук | 120 |
| Красный лак | 200 |
| Сталь | 320 |
| Сакура | 480 |
| Нефрит | 700 |
| Чёрное золото | 1000 |
| Золотые | 2000 |

Первый платный стиль — примерно 4–6 уровней, золотые — долгая цель. Стиль описан данными: градиент вдоль палочки, ширина, блик, кольца и узор (коленца бамбука, насечки, лепестки), поэтому новый стиль добавляется одной записью.

Монеты и купленные стили хранятся в прогрессе (локально и в облаке Яндекса). Монеты могут убывать, поэтому при слиянии копий баланс берётся из более свежей (по счётчику сохранений `rev`), а купленные стили объединяются.

### Реклама за награду

| Где | Награда | Ограничение |
|---|---|---|
| Время вышло | +30 секунд, игра продолжается | один раз за попытку; после продления максимум 2 звезды |
| Экран победы | монеты за уровень ×2 | один раз за победу |
| Магазин | +25 монет | — |

На Яндексе это `showRewardedVideo`, награда выдаётся только после `onRewarded`. Вне Яндекса (локально и в превью) вместо рекламы двухсекундная заглушка, чтобы сценарий можно было проверить. Пока идёт реклама, игра и звук стоят.

### Звук

Все звуки синтезируются в `src/audio/sound.ts`, аудиофайлов нет:

| Событие | Звук |
|---|---|
| Захват зерна | двойной сухой щелчок кончиков палочек |
| Зерно в нужном лотке | стук о дерево и нота ре-минорной пентатоники; чем ближе конец уровня, тем выше нота — сортировка складывается в мелодию |
| Ошибка | глухой удар и низкая нота |
| Выскальзывание | несколько затухающих щелчков |
| Разгребание | непрерывный шорох: громкость и яркость зависят от скорости и числа задетых зёрен |
| Победа / проигрыш | короткая восходящая / нисходящая фраза |
| Кнопки | тихий щелчок |

Звук включается после первого нажатия (так требуют браузеры), выключается кнопкой в HUD или в меню (настройка сохраняется) и приостанавливается на паузе, при сворачивании вкладки, во время рекламы и по событию `game_api_pause` — это требование Яндекс Игр.

### Яндекс Игры

`platform.ts` подгружает `/sdk.js` (так SDK отдаётся на хостинге Яндекса). Если SDK нет — работает локальная заглушка.

- `LoadingAPI.ready()` — когда меню готово.
- `GameplayAPI.start()/stop()` — начало/конец/пауза уровня.
- Полноэкранная реклама между уровнями, начиная с 3-го.
- Прогресс: `player.setData` в облаке и копия в `localStorage`; при загрузке берётся лучшее из двух.
- Пауза при сворачивании вкладки и по событию `game_api_pause`.
- Язык из `environment.i18n.lang`: русский для СНГ, иначе английский.

## Сложность

Кривая `difficulty(n) = 1 − e^{−(n−1)/14}`: 0 на первом уровне, плавно стремится к 1. От неё зависят все параметры (`src/core/level.ts`):

| Параметр | Уровень 1 | Поздние уровни | Что даёт |
|---|---|---|---|
| Виды зёрен | 2 | до 8 | новый вид каждые 3 уровня, он всегда среди целей |
| Лотков (целей) | 1 | до 4 | больше решений на каждое зерно |
| Зёрен всего | ~46 | ~340 | плотнее куча, цели спрятаны |
| Размер зёрен | ×1.25 | ×0.8 | труднее попасть |
| Радиус захвата | 26 | 12 | нужна точность |
| Трение стола | высокое | низкое | куча разъезжается при разгребании |
| Таймер | 5 с на зерно | до 1,7 с на зерно | темп |
| Дрожание палочек | нет | с 8-го уровня | точность |
| Выскальзывание | нет | с 10-го уровня, при быстром движении | аккуратность |
| «Двойники» | нет | с середины кривой | похожие зёрна в смеси (белый рис / белая фасоль, красная чечевица / красная фасоль) |

Уровни 1–3 — обучение, заданы вручную. Остальные генерируются по номеру, одинаково у всех игроков.
