# Мини-игры для Яндекс Игр

Четыре небольшие игры на одном движке-оболочке. Каждая управляется одним касанием или кнопкой мыши, партия длится от полуминуты до нескольких минут, работает на телефоне и компьютере.

| Папка | Игра | Суть |
|---|---|---|
| `tea/` | **Налей чаю** | Зажал — льёшь, отпустил — струя ещё летит. Чай должен встать между чертами. |
| `half/` | **Ровно пополам** | Один взмах — один разрез. Отрежь ровно половину, треть или четверть. |
| `bubble/` | **Пузырёк** | Птицы кренят доску, ты двигаешь грузик и держишь пузырёк уровня в центре. |
| `drain/` | **Водосток** (прототип) | Ливень заливает дорогу, мусор забивает решётку. Сгребай его граблями на тротуар. |

## Запуск и сборка

```bash
npm install
```

```bash
npm run games:dev -- tea
```

```bash
npm run games:build
```

`games:build` собирает все игры в `dist-games/<игра>/` и упаковывает каждую в `dist-games/<игра>.zip` — этот архив загружается в консоль разработчика Яндекс Игр (index.html в корне, все пути относительные). Можно собрать одну: `npm run games:build -- half`.

Добавьте `?debug` к адресу — игра доступна в консоли как `window.__game`.

## Устройство

```
games/
  shared/
    platform.ts   Yandex Games SDK + заглушка для запуска вне Яндекса; сохранения в облаке игрока и localStorage
    shell.ts      меню, пауза, экран итогов, рекорд, звук, реклама — всё, что общее у игр
    stage.ts      холст фиксированного мира, вписанный в экран; игровой цикл с фиксированным шагом
    audio.ts      синтез звуков на Web Audio (без аудиофайлов)
    particles.ts  частицы-окружности: расталкивание, границы, толкатель-отрезок (грабли)
    base.css      общие стили; палитру каждая игра задаёт сама
  tea/ half/ bubble/ drain/
    <игра>.ts     логика без отрисовки — её проверяют тесты
    main.ts       отрисовка, звук, связь с оболочкой
    index.html, style.css
  tests/          тесты логики (Vitest)
  run.mjs         запуск и сборка, упаковка в zip без внешних утилит
```

Каждая игра реализует интерфейс `Game` из `shell.ts`: `start`, `revive`, `update`, `draw`, обработчики касаний, `score`, `over`. Всё остальное делает оболочка.

### Что требует Яндекс Игры и где это сделано

- `LoadingAPI.ready()` — когда показано меню (`shell.ts`).
- `GameplayAPI.start()/stop()` — начало и пауза партии.
- Пауза и тишина при сворачивании вкладки и по событию `game_api_pause`.
- Полноэкранная реклама между партиями, начиная со второй; звук на это время выключен.
- Реклама за награду: после проигрыша — продолжить партию (один раз за партию). Награда выдаётся только после `onRewarded`.
- Рекорд и настройка звука — в облаке игрока (`player.setData`) и копия в `localStorage`.
- Язык из `environment.i18n.lang`: русский для СНГ, иначе английский.
- Нет выделения текста, прокрутки, контекстного меню и браузерных жестов.

Вне Яндекса реклама заменяется двухсекундной заглушкой «Здесь будет реклама Яндекса».

## Баланс

- **Налей чаю.** Струя летит от носика до чашки ~0,45 с — отпускать надо заранее. Полоса между чертами сужается с 22% до 8% высоты чашки; с 9-й чашки они начинают ехать мимо носика, с 16-й напор становится неровным. Три жизни; идеальные наливы подряд умножают очки.
- **Ровно пополам.** Площадь кусков считается по ~6000 точкам сетки (ошибка оценки меньше 0,2%), дырки в сыре честно вычитаются. Ошибка до 1% — «идеально», до 3% — «отлично», до 6% — «почти», больше — минус жизнь. С 6-й еды появляются трети, с 13-й — четверти, с 11-й еда вращается, время на разрез сокращается с 9 до 4,5 с.
- **Пузырёк.** Доска не качается маятником, а вязко клонится к равновесию между птицами и грузиком — иначе за время реакции игрока она проскакивает центр. Перевес птиц на одну сторону никогда не превышает 60% возможностей грузика, поэтому любое положение можно выровнять. Замер ботами: без действий — проигрыш за ~11 с, с реакцией 0,25 с — 25–40 с, с упреждением — около минуты и больше.

- **Водосток.** Вода — сетка 40×60 клеток: дождь добавляет глубину, вода перетекает к соседям, где поверхность ниже (уклон дороги + глубина), решётка забирает её. Расчёт идёт 4 раза за кадр, иначе вода не успевает дойти до решётки. Мусор несёт течением к решётке; на ней он уменьшает пропускную способность (лист — 1, бутылка — 2,5, пакет — 7 из 20). Замер ботами: без действий заливает за ~40 с, при редких мазках — ~2 минуты, при постоянной работе — 5–6 минут; поток мусора растёт без потолка, поэтому партия конечна.

## Публикация в Яндекс Играх

Для каждой игры в [консоли разработчика](https://games.yandex.ru/console/) нужно создать отдельное приложение и загрузить его архив из `dist-games/`. Тексты для карточки:

### Налей чаю

- **Коротко:** Налей ровно до черты — ни каплей больше.
- **Описание:** Неспешная игра на чувство момента. Зажмите экран — чайник наклонится и начнёт лить. Отпустите — но струя ещё долетает до чашки, так что отпускать нужно заранее. Чай должен встать ровно между двумя чертами. Чашки бывают узкие и широкие, со временем они едут мимо носика, а напор становится неровным. Идеальные наливы подряд дают больше очков.
- **Категории:** Казуальные, на ловкость.

### Ровно пополам

- **Коротко:** Один взмах ножа — и никаких «примерно».
- **Описание:** Сыр, пирог, хлеб и пицца неровной формы. Проведите пальцем — это разрез. Отрежьте ровно половину, а дальше — треть или четверть. Игра честно считает площадь кусков, и дырки в сыре не в счёт. Еда становится причудливее, начинает вращаться, а времени на разрез всё меньше.
- **Категории:** Головоломки, казуальные.

### Пузырёк

- **Коротко:** Птицам — доска, вам — строительный уровень.
- **Описание:** На доску на опоре садятся воробьи, голуби и вороны и кренят её. Двигайте грузик влево и вправо и держите пузырёк уровня между отметками. Пока пузырёк вне отметок, тает шкала спокойствия. Птиц становится больше, налетает ветер, отметки сходятся.
- **Категории:** Казуальные, на ловкость.

Скриншоты для карточек лежат в `games/promo/`. Иконку и обложку нужно подготовить отдельно; актуальные размеры — в требованиях Яндекс Игр в консоли.
